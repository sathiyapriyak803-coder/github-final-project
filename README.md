# Simple Interest Calculator

This project calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal amount
- Rate of interest
- Time period

## Output

The calculated simple interest amount.

## Example

Principal = 1000  
Rate = 5%  
Time = 2 years  

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Purpose

This project demonstrates a simple interest calculator using a Bash script.
